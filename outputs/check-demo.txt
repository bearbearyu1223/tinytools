How a call is checked
--------------------------------------------------------------------------
  exact match: one call, the reference's tool, the same arguments
    after normalizing argument order, number format (90 = 90.0) and
    whitespace; an expression compares as a syntax tree.
  execution match: one call, the reference's tool, run on fresh data;
    no error, and the same result: searches return the same set,
    a created event leaves the same calendar, numbers agree within
    1e-06 relative (or 1e-09 absolute).
