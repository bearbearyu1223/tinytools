Setup
--------------------------------------------------------------------------
  model                              Qwen/Qwen2.5-0.5B-Instruct
  dtype                              float32
  determinism                        not set on mps (the CUDA flags only)
  greedy, our tasks                  60: first 20 test tasks per kind
  greedy, BFCL                       40: first 8 eval items per category
  sampled, our tasks                 10: the first test tasks by id
    decoding                         8 samples, temperature 1
  top_p / top_k / repetition penalty 1.0 / off / 1.0
  max new tokens                     512
  seed                               0
  One at a time (the replaced engine): Hugging Face generate on one
  prompt, torch.manual_seed(seed + crc32(item id)) before it; its
  8 samples are one generate call with 8 return sequences.
  Batched (the engine every capture now uses):
  engine                             batched, sorted by length
    batch size, greedy               8 sequences
    batch size, 8 samples            8 sequences (1 item x 8)
  Left padding with the attention mask; a reply ends at the model's
  eos or <|im_end|>. Seconds per item: the batch's seconds x the
  item's share of its rows.
  Its samples: each reply draws from its own generator seeded with
  the seed, item id and sample number (engine.py says how).
